# 定期承接（jg-deposit-jiepan）

| 项 | 值 |
|---|---|
| 板块 / 分组 | 个金 / 增存 |
| 类型 | 数据模块（metric） |
| 数据源 | 定期承接客编明细（Sheet1，18 列；核心列见下） |
| 粒度 | 网点（40 个营业网点）+ 支行（8 家） |
| 频率 | 周 |
| as_of | 取数日 = 表里 `最近到期日期` 的**最大值** |
| coverage | `[最近到期日期最小值, 最大值]`，固定 31 天（当日往前一个月） |
| 导入 | `viz.import_jiepan` → `IMPORTERS['jp']` |
| 解析 | `src/ingest/jiepan.py`（`parse` / `aggregate` / `parse_files`） |
| 视图 | `api.build_jiepan` → `BUILDERS['jiepan']` / `LINE_OF['jiepan']='jp'` |
| 页面 | `pages/jiepan.js`，路由 `#/m/jg-deposit-jiepan` |
| 通报 | `report.build_jiepan` / `jiepan_xlsx`，`CAT_OF['jiepan']='jg'`，母版 `jiepan_base.xlsx` |
| 口令可见 | 个金口令、管理员 |

## 字段映射

| 源表列 | 内部字段 | 说明 |
|---|---|---|
| 归属支行名称 | `branch` | 8 家支行 |
| 机构名称 | `net` | 网点，实体网点才计入 |
| 客户编号 | `custno` | 只用于排除名单 |
| 近30天到期金额 | `due_amt` | **承接率的分母** |
| 最近到期日期 | `due` | 窗口筛选用，也是 as_of |
| 定期余额变化 | `bal_d` | 未承接金额 = 这列求和 |
| 时点资产变化 | `ast_d` | 资金承接率的分子部分 |
| 30天前/当前 定期、存款、资产 | `bal30` `bal` `dep30` `dep` `ast30` `ast` | 只作参考，**不参与计算** |

## 口径

- 定期承接率 = (到期金额 + 定期余额变化) / 到期金额
- 资金承接率 = (到期金额 + 时点资产变化) / 到期金额
- 未承接金额（万元）= Σ 定期余额变化 / 10000
- 网均未承接 = 支行未承接 ÷ 该支行网点数
- 综合评价 = 网均名次×0.4 + 定期率名次×0.4 + 资金率名次×0.2（**降序名次**，总分**升序**，并列同名次跳号）
- 优秀先锋 = 网点定期承接率降序前 8
- **窗口可在 coverage 内任取**；默认 = 取数日往前 7 天（含头尾）

## 导入前手工改明细（0.1.7.1）

- 入口：导入页选到本模块 → 「④ 手动编辑明细（可选）」卡片
- 交互：输 `客户编号` → `POST /api/jiepan/find`（带当前待导入的文件）→ 返回该客编的行
  （只回 `EDIT_FIELDS` 里的四列 + 只读的支行/网点/30天前与当前余额）
- 编辑：`最近到期日期`、`近30天到期金额`、`定期余额变化`、`时点资产变化`
- 提交：`overrides`（JSON）随 `/api/import` 一起回传，服务端按 `(客编, 机构, 到期日)` 覆盖，
  再走正常解析；`notes` 里会写「导入前手工修改 N 行」
- **可选**：不改就照原样导入；只影响这一次导入，源文件不动
- 典型用法：到期后资产整体流失、不该算网点未承接的客户 → 把 `定期余额变化` 与
  `时点资产变化` 都改 0（到期金额仍留在分母），与人工成表口径一致

## 已知坑

1. **不要跨快照合并**：`30天前余额` 的基准日跟着导出日滚动，跨批次数值不可比。
2. 分母是**到期金额**，不是 30 天前余额（差很大）。
3. 并列第 1 时后续跳号（阜南、颍泉可并列 1，下一个是 3）。
4. `XX支行营业室` 是网点不是支行；`运行管理部` 要排除（40 个网点）。
5. 官方成表 G12 合计资金承接率算错（公式只到 4902 行），系统按全量算，会比它高 0.0076。
6. 大额整体流失户是人工改源表（两列改 0），不是阈值规则；现在可在导入页手工改，
   不必再动源文件（`parse(exclude=…)` 保留同样的"两列置 0"语义，供脚本用）。
7. 导出走 `xlsx_keep.save_like(JIEPAN_BASE, wb)`，别直接 `wb.save()`（母版里有图片时会被丢，见 HANDOFF 8.12）。
