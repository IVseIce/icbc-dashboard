# 私人银行（pbs-cust）

| 项 | 值 |
|---|---|
| 板块 / 分组 | 私人银行 / 私人银行 |
| 类型 | 数据模块（metric） |
| 数据源 | 客编日均资产明细（`归属支行名称` / `归属网点名称` / `当月月日均资产` / `本月存款日均`） |
| 粒度 | 支行（8 家）+ 网点（40 个固定清单） |
| 频率 | 旬（当前按日导入也没问题，一天一期） |
| as_of | 文件名识别的日期；认不出由前端手填 |
| 导入 | `viz.import_pbs` → `IMPORTERS['pbs']` |
| 视图 | `api.build_pbs` → `BUILDERS['pbs']` / `LINE_OF['pbs']='pbs'` |
| 页面 | `pages/pbs.js`，路由 `#/m/pbs-cust` |
| 通报 | `report.build_pbs` / `pbs_xlsx`，`CAT_OF['pbs']='pbs'`，母版 `pbs_base.xlsx` + `pbs_dev_base.xlsx` |
| 口令可见 | 私银口令、管理员 |

## 字段映射

| 源表列 | 快照字段 | 说明 |
|---|---|---|
| 归属支行名称 | 用于归到 8 家支行 | 4 个别名见下 |
| 归属网点名称 | `nets[].name` | 固定 40 个，不在清单的只并支行 |
| 客户编号 | 计数 / 去重 | 同一客编重复只算一次 |
| 本月月日均资产 | `asset`（元，展示转万元） | 成表「资产」 |
| 本月存款日均 | `dep`（元） | 成表「日均存款」 |
| 本月基金日均 | `fund` 人数 | 渗透率分子 |
| 本月理财产品（零售/私人银行）日均 | `wmp` 人数 | 两者相加 > 0 算一户 |
| 本月银保通日均 | `ins` 人数 | 渗透率分子 |

## 口径

- **支行归属别名**（对着成表验算确认，别改）：
  - `阜阳牡丹支行` → 颍泉
  - `阜阳文峰支行` → 颍州
  - `阜阳城建支行` → 颍州
  - `阜阳汇通支行` → 颍东
- 其余按名前缀归（颍州/颍泉/颍东/界首/临泉/阜南/颍上/太和）
- 三个时点：**当天**（`as_of`）、**上年末**（算"比上年"）、**上季度末**（算"比9月末"）。
  后两个存成 `partial=True` 快照，只补基线、不进详情页
- 网点清单固定 40 个（含当期 0 户的岳家湖、颍上十字街），存在 `report/assets/pb_nets.json`
- 产品销售 7 项**不在明细里**，是人工维护，存 `setting.pbs_sales`，导入/保存时合进快照
- 单位：源表是**元**，快照存元，`api` 层转万元

## 已知坑

- **源表里没有日期**：必须靠文件名（`20261024` / `10.24` / `1024` 都认），认不出要提示手填
- **源表「归属支行」有 12 个值**，其中 4 个不在 8 家支行里（见上表），不映射就会少算
- 早期两份基线文件（`20251231.xlsx` / `20260930.xlsx`）被脱敏成 `zero`/`abondon` 字符串，
  清洗后放在同目录 `（已清洗）/`，正式数据不会再这样
- 颜色是**条件格式**（好 2 红 / 坏 2 绿），别手工涂色；发展情况的「存量客户=0」标黄是单元格填充
- `pbs_xlsx` 要把两个母版合成一个工作簿，`_copy_sheet` 里必须先 `unmerge_cells`，
  否则写 `MergedCell` 会抛 read-only
